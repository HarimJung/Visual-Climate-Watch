## 3. Rules that cannot be broken (the product is these)

- `unknown ≠ absent`. The word for an unread figure is "not read", never "not found", never "not filed". A `refused` blank says "refused" and quotes the reason.
- No invented numbers. No interpolation, no ranks, no grades (PRD §8). No ratios computed in the UI (the "18 % of $357m" sentence mixed a single-country numerator with approvals that include regional shares; show the view's own `disbursed_pct` only where the view provides it, labelled as the view's). No cross-basis deltas (2030 BAU against a 1990 inventory). No sums across sources. No need-minus-received.
- Every sentence on screen is either a fixed label or a sentence the record holds (verdict clause, `$reason`, evidence sentence, conditionality statement, scope sentence, `$meta.notice`). Never show `$note` (engine-internal). Never write a reason.
- Screen figures = `data/census.json` / the record. Nothing counted a second way.
- Design: white page only; Bricolage Grotesque display (`--font-display`), Hanken Grotesk body (`--font-sans`), tabular figures; UN blue `--un` for the brand, SDG colours only on evidence (`--inv` green observations, `--btr` magenta report, `--fin` gold finance, `--src-a..d` greys for sources, `--ssp126/245/370/585` for scenarios); no black; hairlines `--rule`, no boxed cards, no drop shadows except the scene's ground; motion 600–800 ms on `--out`, staggers ≤ 500 ms, reduced motion off; no em dash in copy; no engine nouns ("calibre", "this engine" in page copy; a quoted record sentence may contain them).

## 5. The structure (decided and approved; from the red team, all three lenses)

L0 KPI strip → L1 record cover (no part selected) → L2 part sheet (one part) → L3 figure receipt (the side sheet, one `/api/v1/receipt` + one `/api/v1/related` call) → L4 the source file (link + hash). Every printed number is a `<Fig>` whose path is its record path. Compare = a keyed two-column diff for the selected part with a basis guard. KPI figures open the world view they were counted from. "Find in the record" = retrieval over the record's own sentences, quoted with paths, with one fixed sentence when nothing matches; never generated prose. The tour gets a refusal chapter and a provenance chapter. The 3D keeps its one rule: a part the record cannot fill is not drawn.

Must not be built: ranks (also strip `rank` from `/api/v1/related`, see §6 orchestrator), cross-basis pledge deltas, summed sources, interpolation, need-minus-received, any prose generation.

## 8. Pitfalls learned this session

- A `perl -0pi` multi-substitution emptied `readout.tsx` once. Use the Edit tool on files you did not write; `recover-file.mjs <agent transcript> <file>` replays a subagent's Write/Edit/heredoc operations from `~/.claude/projects/<project>/<session>/subagents/agent-*.jsonl`.
- Session rate limits cut three agents near completion; the orchestrator finished each. Keep each agent's scope finishable in about forty minutes, have them write files early, and read their transcript if they go silent.
- HMR serves stale CSS: run `restart-dev.sh` after stylesheet edits (a ten-second blip).
- The 3D needs 12–16 s to go live headless (SwiftShader); set `--virtual-time-budget=16000` or wait in Playwright before judging the scene.
- Playwright MCP: one agent at a time; it saves only under the repo's `.playwright-mcp/`.
- `Response.json(d)` re-serialises the record, so the served bytes differ from `public/data/countries/KHM.json`; the content is the same. The record files on disk: `data/countries/*.json` (source of the static copy), `public/data/countries/*.json` (served), `data/golden/*.json` (verify set). Never rebuild them locally.
- Record key names that tripped a probe today: `ndc.folu_share_of_reduction_pct` (not `folu_share_pct`), the notice is the root `$meta.notice`, the GCF rows are `finance_flows.received[]`. `lib/story.ts` reads all three correctly.
- `tests/world.test.ts` pins the BTR denominators and the headline-row dot count; `tests/receipt.test.ts` pins KHM page 150 / by hand / PDF url and DEU joint / page 6; `tests/story.test.ts` pins the finance `received_state`, the flows row count, the hand reading, the notice, three vintages and the refused gap.
