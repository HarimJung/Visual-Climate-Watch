3.1 Agentforce 구성 개요
Visual Climate의 AI 레이어는 Salesforce Agentforce 3 위에 구축됩니다. Agentforce 3의
Atlas Reasoning Engine은 hybrid reasoning을 지원합니다 — LLM의 유연한 자연어 이해와
Agentforce Script의 결정론적 비즈니스 로직을 결합합니다. 이 hybrid 접근이 기후 데이터
플랫폼에 필수적인 이유는, AI가 "캄보디아의 에너지 섹터 배출이 증가한 이유를
설명해줘"라는 자연어를 이해해야 하면서도, "소스를 인용하지 않은 해석은 절대
사용자에게 보내지 마라"라는 규칙은 예외 없이 강제해야 하기 때문입니다.

Agentforce의 공식 구성 요소와 Visual Climate의 매핑은 다음과 같습니다.

Primary Agent는 사용자의 모든 질의를 받는 단일 진입점입니다. Atlas Reasoning Engine이
각 Subagent의 이름, 설명, Instructions, 사용 가능한 Actions를 검토하여 최적의 Subagent에
작업을 위임합니다. 사용자는 Subagent의 존재를 모르고, 하나의 대화 스레드에서
연속적으로 질문합니다.

S03 — Explanation
Subagent: Explanation
━━━━━━━━━━━━━━━━━━━━━

이름: ClimateDataExplainer

설명 (Topic Scope):
 "Provides plain-language interpretation of climate data and
  visualizations. Explains trends, anomalies, comparisons, and
  context. Every explanation must cite specific data sources
  and years. Responds in the user's language."


 ✅
Topic Classifier Examples:

 ✅
    "이 그래프 설명해줘"

 ✅
    "왜 배출이 2018년에 급증했어?"
    "What does this vulnerability score mean?"
 ✗ "데이터 보여줘" → S01
 ✗ "비교해줘" → S04

Instructions:
 1. "Structure every explanation as:
    WHAT (the data shows) → WHY (possible reasons) → SO WHAT (implications).
    Keep WHAT purely factual. Keep WHY hedged ('likely due to', 'possibly
    related to'). Keep SO WHAT forward-looking but not prescriptive."
 2. "When explaining trends, always state: direction, magnitude (%),
    absolute change, time period, and source."
 3. "When two sources disagree, explain both values and the methodological
    reason. EDGAR uses top-down energy statistics; Climate TRACE uses
    bottom-up satellite observation + ML. Neither is 'wrong' — they
    measure differently."
 4. "For ND-GAIN vulnerability, always decompose into components
    (exposure, sensitivity, adaptive capacity) rather than just
    stating the composite score."
 5. "Never make causal claims without evidence.
    'CO₂ increased' ≠ 'CO₂ caused temperature increase'
    unless citing IPCC attribution studies."
 6. "If confidence < 0.7, respond: 'The available data is insufficient
    for a reliable interpretation.'"
 7. "Adapt complexity to apparent user expertise:
    - Simple language for general users
    - Technical terminology for users who demonstrate expertise
      (e.g., mentioning BTR, IPCC methodology, GWP values)"

3.4 품질 게이트 7개 — 구현 상세
모든 사용자에게 표시되는 콘텐츠는 7개 품질 게이트를 통과해야 합니다. 이 게이트는 Apex
Action으로 구현되어, Subagent의 Agentforce Script 마지막 단계에서 호출됩니다. 하나라도
false면 콘텐츠 상태가 ready가 될 수 없습니다.

public class VC_QualityGateChecker {

  @InvocableMethod(label='Check All Quality Gates'
              description='Runs 7 quality gates on content')
  public static List<GateResult> checkAllGates(List<GateInput> inputs) {
    GateInput input = inputs[0];
    GateResult result = new GateResult();

    // ═══════════════════════════════════════════════════
    // Q1: SOURCE CITATION
    // 모든 수치에 [Source: DS-XX, Year: YYYY] 형태의 인용이 있는가
    // ═══════════════════════════════════════════════════
    result.Q1_sources = true;
    Pattern citationPattern = Pattern.compile(
       '\\[Source: DS-\\d{2}, Year: \\d{4}\\]');
    // 텍스트에서 모든 숫자 추출
    List<String> numbers = extractNumbers(input.contentText);
    for (String num : numbers) {
       // 각 숫자 주변 100자 이내에 citation이 있는지 확인
       if (!hasCitationNearby(input.contentText, num, citationPattern, 100)) {
           result.Q1_sources = false;
           result.Q1_failedNumbers.add(num);
       }
    }

    // ═══════════════════════════════════════════════════
    // Q2: DATE RANGE
    // 인용된 연도가 해당 소스의 실제 temporal_coverage 안에 있는가
    // ═══════════════════════════════════════════════════
    result.Q2_dates = true;
    for (Citation c : input.citations) {
       SourceMetadata sm = getSourceMetadata(c.sourceId);
       if (c.year < sm.temporalCoverageStart ||
           c.year > sm.temporalCoverageEnd) {
           result.Q2_dates = false;
           result.Q2_failedCitations.add(c);
       }
}

// ═══════════════════════════════════════════════════
// Q3: UNITS
// 표시된 단위가 데이터의 실제 단위와 일치하는가
// 변환이 있었다면 변환이 정확한가
// ═══════════════════════════════════════════════════
result.Q3_units = true;
for (DataRecord dr : input.dataRecords) {
   String displayedUnit = extractDisplayedUnit(
       input.contentText, dr.indicatorId);
   if (displayedUnit != null &&
       !isUnitConsistent(dr.unit, displayedUnit)) {
       result.Q3_units = false;
       result.Q3_unitMismatches.add(
          dr.indicatorId + ': data=' + dr.unit +
          ' display=' + displayedUnit);
   }
}

// ═══════════════════════════════════════════════════
// Q4: COMPARABILITY
// 비교된 데이터 간 기준연도, 가스 범위, 공간경계가 호환되는가
// ═══════════════════════════════════════════════════
result.Q4_comparability = true;
if (input.isComparison) {
    ComparabilityCheck cc = checkComparability(input.comparisonItems);
    if (cc.hasBlockers) {
        result.Q4_comparability = false;
        result.Q4_blockers = cc.blockers;
    } else if (cc.hasWarnings) {
        result.Q4_warnings.addAll(cc.warnings);
        // 경고는 있되 통과 — 경고가 응답에 포함되었는지 확인
        if (!input.contentText.contains(cc.warnings[0].substring(0,30))) {
            result.Q4_comparability = false; // 경고 미포함이면 실패
        }
    }
}

// ═══════════════════════════════════════════════════
// Q5: UNCERTAINTY
// 불확실성이 있는 데이터(전망, Fast Track 추정 등)에
// 불확실성 범위 또는 주의사항이 표시되었는가
// ═══════════════════════════════════════════════════
result.Q5_uncertainty = true;
for (DataRecord dr : input.dataRecords) {
   if (requiresUncertainty(dr)) {
       // Fast Track 추정, 시나리오 전망, 보간값 등
                if (!hasUncertaintyInfo(input.contentText, dr)) {
                    result.Q5_uncertainty = false;
                    result.Q5_missingUncertainty.add(dr.indicatorId + '/' + dr.year);
                }
            }
        }

        // ═══════════════════════════════════════════════════
        // Q6: AI DISCLOSURE
        // "AI로 생성된 해석입니다" 문구가 포함되어 있는가
        // ═══════════════════════════════════════════════════
        result.Q6_aiDisclosure = input.contentText.containsIgnoreCase(
            'AI-generated') || input.contentText.containsIgnoreCase(
            'AI가 생성한') || input.contentText.containsIgnoreCase(
            'généré par l\'IA'); // 6개 언어 변형 체크

        // ═══════════════════════════════════════════════════
        // Q7: HUMAN SIGN-OFF
        // BTR 관련 콘텐츠이면 인간 reviewer가 승인했는가
        // ═══════════════════════════════════════════════════
        if (input.isBTRRelated) {
            result.Q7_humanSignoff = input.humanApproved;
        } else {
            result.Q7_humanSignoff = true; // BTR 아니면 자동 통과
        }

        // ═══════════════════════════════════════════════════
        // 종합 판정
        // ═══════════════════════════════════════════════════
        result.allPassed = result.Q1_sources && result.Q2_dates
           && result.Q3_units && result.Q4_comparability
           && result.Q5_uncertainty && result.Q6_aiDisclosure
           && result.Q7_humanSignoff;

        result.failedGates = new List<String>();
        if (!result.Q1_sources) result.failedGates.add('Q1_SOURCES');
        if (!result.Q2_dates) result.failedGates.add('Q2_DATES');
        if (!result.Q3_units) result.failedGates.add('Q3_UNITS');
        if (!result.Q4_comparability) result.failedGates.add('Q4_COMPARABILITY');
        if (!result.Q5_uncertainty) result.failedGates.add('Q5_UNCERTAINTY');
        if (!result.Q6_aiDisclosure) result.failedGates.add('Q6_AI_DISCLOSURE');
        if (!result.Q7_humanSignoff) result.failedGates.add('Q7_HUMAN_SIGNOFF');

        return new List<GateResult>{ result };
    }
}

3.5 금지 행위 9개 — 기술적 강제 방법
RFP §14의 9개 금지 행위는 세 가지 수준에서 강제됩니다.

수준 1: Agentforce Global Guardrails — Primary Agent 수준에서 block 규칙으로 정의.
Atlas Reasoning Engine이 라우팅 단계에서 해당 Action을 선택하지 않음.

수준 2: Agentforce Script — 각 Subagent의 Script에서 금지 Action을 호출하는 step이
존재하지 않음. 만약 LLM이 Script를 벗어나려 하면 Script의 결정론적 로직이 차단.

수준 3: Apex Action 검증 — CheckQualityGates Apex에서 출력 텍스트를 스캔하여
금지 패턴 탐지 (예: 순위 표현 정규식, “will” + 미래 시제 탐지, 인과관계 주장 패턴).
    금지 행위       Guardrail    Script   Apex 검증

      1.​ 국가 순위 자동 생성|block: GenerateCountryRanking|S04에 순위 step
          없음|텍스트에서 “ranks #”, “위” 패턴 탐지
      2.​ 법률/금융 자문|block: ProvideFinancialAdvice, ProvideLegalAdvice|모든
          Subagent에서 해당 Action 없음|“should invest”, “legal obligation” 패턴
      3.​ 멸종위기종 위치 공개|block: DiscloseEndangeredSpeciesLocations|S12에서 좌표
          반환 안 함|좌표 형태 숫자 탐지
      4.​ 비승인 정책 제출|block: SubmitPolicyRecommendationsAsOfficial|S10에서
          “recommend” 대신 “data suggests”|“should adopt”, “must implement” 패턴
      5.​ Tableau MCP 로그인 접근|block: AccessTableauMCPLogin|Tableau API 호출은

1. 기준연도가 다른 두 소스의 % 변화를 자동 계산하지 않음.
  예: EDGAR (2005 기준 -20%) vs NDC (1990 기준 -40%) →
  직접 비교 금지, 각각 원본 기준연도와 함께 표시.

2. 공간경계가 다른 두 소스를 자동 비교하지 않음.
  예: WDI (본토만) vs EDGAR (해외영토 포함) →
  S04 ComparabilityChecker가 blocker로 판정.

3. Imputation (결측 보간)은 S14 전용, 인간 승인 없이 불가.
  DLO → DMO 변환 단계에서 결측은 null로 유지.
  null은 시각화에서 "데이터 없음"으로 명시적 표시.

4. 서로 다른 소스의 값을 평균내지 않음.
  EDGAR 100 Mt + Climate TRACE 110 Mt → 평균 105 Mt (금지).
  둘 다 별도 행으로 저장, 둘 다 표시.

구현: Data Cloud Transform Rules에서 null 보존 설정,
  Apex Action에서 금지 패턴 탐지.

// components/tableau/TableauEmbed.tsx
'use client';

import { useEffect, useRef, useState } from 'react';
import {
  TableauViz,
  useTableauVizRef,
  useTableauVizFirstInteractiveCallback,
  useTableauVizFilterChangedCallback,
  useTableauVizMarkSelectionChangedCallback
} from '@tableau/embedding-api-react';

interface TableauEmbedProps {
  workbookPath: string;          // e.g., "CountryProfiles/CP_Emissions"
  filters?: Record<string, string>; // e.g., { Country: "KHM" }
  height?: number;
  device?: 'desktop' | 'phone' | 'tablet';
  onFilterChange?: (field: string, values: string[]) => void;
  onMarkSelect?: (data: any) => void;
  onReady?: () => void;
}

export default function TableauEmbed({
  workbookPath,
  filters = {},
  height = 600,
  device = 'desktop',
  onFilterChange,
  onMarkSelect,
  onReady
}: TableauEmbedProps) {
  const vizRef = useTableauVizRef();
  const [token, setToken] = useState<string | null>(null);
  const [loading, setLoading] = useState(true);

 // JWT 토큰 가져오기
 useEffect(() => {
   fetch('/api/tableau-token', { method: 'POST' })
     .then(res => res.json())
     .then(data => setToken(data.token));
 }, []);

 // Tableau가 인터랙티브 상태가 되면
 const onFirstInteractive = useTableauVizFirstInteractiveCallback(() => {
  setLoading(false);
  onReady?.();
}, [onReady]);

// 필터 변경 이벤트
const onFilterChanged = useTableauVizFilterChangedCallback((event) => {
  const { fieldName } = event.detail;
  // 필터 값 추출
  const worksheet = vizRef.current?.workbook?.activeSheet;
  if (worksheet && onFilterChange) {
    // Tableau Embedding API v3에서 필터 값 가져오기
    worksheet.getFiltersAsync().then(filters => {
      const filter = filters.find(f => f.fieldName === fieldName);
      if (filter) {
        onFilterChange(fieldName, filter.appliedValues?.map(v => v.value) || []);
      }
    });
  }
}, [onFilterChange]);

// 마크 선택 이벤트
const onMarkSelectionChanged = useTableauVizMarkSelectionChangedCallback(
  (event) => {
    const marks = event.detail;
    onMarkSelect?.(marks);
  }, [onMarkSelect]
);

if (!token) return <div className="animate-pulse h-96 bg-gray-100 rounded" />;

// URL에 필터를 쿼리 파라미터로 포함
const filterParams = Object.entries(filters)
  .map(([key, val]) => `${encodeURIComponent(key)}=${encodeURIComponent(val)}`)
  .join('&');

const src = `https://visualclimate.tableau.com/views/${workbookPath}`

export class AgentforceClient {
 private accessToken: string | null = null;
 private instanceUrl: string;

    constructor() {
      this.instanceUrl = process.env.SALESFORCE_INSTANCE_URL!;
    }

    async authenticate(): Promise<void> {
    // OAuth 2.0 JWT Bearer Flow
    const jwtAssertion = this.createJWTAssertion();
    const response = await fetch(`${this.instanceUrl}/services/oauth2/token`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
      body: new URLSearchParams({
        grant_type: 'urn:ietf:params:oauth:grant-type:jwt-bearer',
        assertion: jwtAssertion
      })
    });
    const data = await response.json();
    this.accessToken = data.access_token;
}

async sendMessage(
  sessionId: string,
  message: string,
  context?: { country?: string; page?: string; visualization?: string }
): Promise<AgentResponse> {
  if (!this.accessToken) await this.authenticate();

    const response = await fetch(

        method: 'POST',
        headers: {
          'Authorization': `Bearer ${this.accessToken}`,
          'Content-Type': 'application/json'
        },
        body: JSON.stringify({
          agentId: process.env.AGENTFORCE_AGENT_ID,
          sessionId,
          message,
          context: {
            ...context,
            platform: 'visual_climate_web',
            timestamp: new Date().toISOString()
          }
        })
      }
    );

    return response.json();
