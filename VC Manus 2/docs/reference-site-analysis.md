# Reference site analysis

Reference: https://global-knowledge-index-2026.vercel.app/

The site uses a compact utility header, text-first top navigation, a large country/topic heading, a high-contrast score or headline block, numbered analytical sections, and dense source-aware tables. Its page text separates overall score, rank, sub-index performance, five-year history, strengths, priority areas, and source/methodology notes. The visual system is light and editorial: white canvas, black oversized headings, blue structural accents, thin rules, restrained cards, and clear table hierarchy. Visual Climate reuses these principles only at the level of information hierarchy and editorial clarity; it does not copy the site’s brand, copy, exact layout, or assets.

Product implication: Visual Climate should surface a country or analysis topic first, then present conditions, evidence, checks, interpretation, and export in numbered sections. The hero must answer what the product does, while the main body must answer what the current result means and whether it can be compared or reused.
