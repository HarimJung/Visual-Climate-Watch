# High-trust climate data implementation standards

## IPCC uncertainty guidance

Source: https://www.ipcc-nggip.iges.or.jp/public/2006gl/pdf/1_Volume1/V1_3_Ch3_Uncertainties.pdf

The IPCC Guidelines distinguish uncertainty from inter-annual variability and discuss model uncertainty, empirical data, expert judgement, probability density functions, confidence/coverage intervals, and temporal correlation. Visual Climate therefore carries an uncertainty field with each estimate and treats the current intervals as indicative demonstration intervals until source-specific uncertainty data are connected.

## UNFCCC transparency and review

Source: https://unfccc.int/Transparency

UNFCCC transparency arrangements cover regularly available information on greenhouse-gas emissions, policies and measures, progress toward targets, climate impacts and adaptation, support, and capacity-building needs. The product now keeps conditions, source metadata, quality gates, limitations, and provenance alongside values, while clearly labelling simulated demonstration values.

## FAIR data principles

Source: https://www.go-fair.org/fair-principles/

FAIR requires persistent identifiers, rich metadata, explicit links between metadata and data, searchable registration, standard retrieval protocols, accessible metadata, formal vocabularies, qualified references, licensing, and detailed provenance. The current implementation adds retained query filters, dataset identifiers, units, uncertainty text, data mode, and provenance fields. Remaining work includes persistent dataset/version identifiers, licensing metadata, schema validation, and source-specific lineage.
